# Product spec (v0.1, to confirm with suppliers)

Targets marked **[confirm]** come from typical OEM menstrual heat patches. Replace each with the supplier's tested value before it appears on packaging.

## The patch

| Item | Target |
|---|---|
| Type | Disposable, air-activated, adhesive heat patch, worn on underwear |
| Size | about 95 x 130 mm, rounded corners [confirm, pick from OEM standard sizes] |
| Thickness | ≤ 3 mm [confirm] |
| Heat-up | warm within 5 to 10 minutes of opening [confirm] |
| Duration | up to 8 hours above 40°C [confirm] |
| Average temperature | about 42 to 48°C [confirm] |
| Maximum temperature | ≤ 55°C measured per JIS S 4100 or equivalent [confirm] |
| Core | iron powder, activated carbon, vermiculite, salt, water |
| Core design | **celled / segmented** (needed for "even heat" and "flexible" claims) |
| Cover | soft non-woven, brushed feel, lilac color if MOQ allows, else white |
| Adhesive | skin-friendly, hypoallergenic grade, sticks to cotton, peels clean |
| Release liner | printed "peel here" or plain |
| Additives | none. No fragrance, no essential oils, no drugs (launch version) |
| Shelf life | 3 years unopened [confirm] |

## Inner sachet (the airtight pouch)

The sachet is functional: it is the oxygen barrier that keeps the patch inactive. It must be made and sealed by the OEM on their barrier film. We supply artwork only.

| Item | Target |
|---|---|
| Material | OEM barrier laminate, matte finish, custom print (lavender front, lilac-mist back) |
| Size | OEM standard for the chosen patch |
| Seals | heat-sealed with crimp, tear notch at top |
| Print | 4-color or 2 spot colors + white. See `packaging/sachet-spec.md` |

## Outer box

Ours to design and produce (OEM or a separate printer). See `packaging/box-spec.md`.

## Documents to request from the supplier

- Ingredient list with percentages (for customs and labeling)
- MSDS / SDS
- Temperature curve test report (time vs temperature), JIS S 4100 or equivalent
- Dermatological test for the adhesive (HRIPT or patch test) if we claim "hypoallergenic"
- Shelf-life / stability data
- Factory certificates: ISO 9001 at minimum; ISO 13485 is a plus
- CE / FDA registration if they have it (helps credibility, not required for UAE general goods)
- Certificate of Origin and commercial invoice templates for UAE customs
